Database Management Features

Demonstrating core academic database concepts implemented in PostgreSQL & Supabase.

⚡

Automatic Triggers

Triggers automatically calculate total_marks and assign grades (A+, A, B+, etc.) upon mark entry, and compute attendance percentage.

📊

Database Views

Created student_marks_view and student_attendance_view to join multiple normalized tables (Students, Subjects, Marks) without redundant queries.

🛡️

Row Level Security (RLS)

Enforced PostgreSQL security policies so students can strictly access only their personal academic performance, while administrators retain full CRUD control.

🔗

Relational Integrity

Uses strict Primary Keys (UUID), Foreign Keys with ON DELETE CASCADE, Unique Constraints on Roll No & Enrollment No, and Check Constraints.

⚙️

Stored Stored Function

calculate_attendance_percentage() safely handles division-by-zero errors when total class sessions are zero or pending.

🚀

Optimized Indexes

B-Tree indexes on roll_no, enrollment_no, student_id, and subject_id ensure high query throughput.
